# Faizi Ahmad — Portfolio

Single-file portfolio website designs. Open `index.html` to pick a version.

| File | Design |
|------|--------|
| `red.html` | Original dark design, red accent |
| `blue.html` | Original design, electric blue, smaller type |
| `violet.html` | Original design, violet, smaller type |
| `green.html` | Original design, emerald green, smaller type |
| `light.html` | Warm light layout, plain-English copy |
| `futuristic.html` | Hardware-inspired layout, plain-English copy |

## Hosting

Turn on GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
To make one design the homepage, rename it to `index.html`.

## Before going live

Search each page for `[X]`, `[YOUR EMAIL]`, `[YOUR-HANDLE]` and `TODO` and fill in your details.
